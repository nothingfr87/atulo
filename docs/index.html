ATULO

AUDIO PLAYER WRITTEN IN C

A small terminal program made to play audio files.

[ SOURCE CODE ]

01 / FORMATS

MP3

WAV

OGG

OPUS

FLAC

AIFF

02 / INTERFACE

Atulo works directly from the terminal. Its interface is built with ncurses and its audio support comes from the embedded miniaudio.h library.

03 / CONTROLS

p / Space Pause
q / Escape Exit
r Replay from start
→ Skip 5 seconds
← Go back 5 seconds

04 / BUILD

BUILD

$ make clean build

INSTALL

$ sudo make clean install

UNINSTALL

$ sudo make uninstall

05 / REQUIREMENTS

GCC

ncurses

miniaudio.h
